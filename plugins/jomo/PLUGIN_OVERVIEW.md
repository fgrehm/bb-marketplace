JOMO explores a calm, reading-first way to use BB. It holds a large feed as a hoard rather than an inbox, makes deliberate keeping easy, and treats unread material as potential rather than debt.

This release is an offline UI prototype with four connected surfaces:

- A first-run librarian interview with five skippable questions.
- A draft taste-profile review and persistent, human-editable Markdown notebook.
- A 300+ item feed with cards, keyboard triage, swipe actions, undo, filters, and a one-item-at-a-time sweep mode.
- A JOMO report that shows why missing the rest was safe.

The librarian profile is stored through the plugin backend. Suggested interests and source priors remain drafts until the user confirms them. AI-shaped surfaces render outcomes and explanations, but do not silently mutate feed state.

The plugin remains deliberately offline. Future iterations can add real RSS and Atom fetching, article extraction, durable feed storage, bulk queue operators, and a backlog/reservoir view without changing the interaction model proven here.
