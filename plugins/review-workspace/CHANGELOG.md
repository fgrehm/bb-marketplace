# Changelog

## [0.1.0] - 2026-09-29

### Added

- Review uncommitted changes, a selected commit, or a committed branch comparison through immutable revisions.
- Anchor feedback to diff lines or files, add a review note, mark files as viewed, and send selected feedback to the agent with relevant diff context.
- Carry unresolved comment threads and the review note forward when refreshing; retain previous revisions.
- Add agent tools for preparing reviews, inspecting revision status, commenting, resolving, finding, and importing review feedback.
- Add the experimental Entities view, powered by local sem tooling, alongside the regular diff view.
